# Affinity Core RCM website

React 18 + TypeScript + Vite prototype for affinitycore RCM.

- Live: https://api-agencypartner.github.io/affinitycore-rcm/
- Every push to `main` builds and deploys to GitHub Pages (`.github/workflows/deploy.yml`).
- Local: `npm ci && npm run dev`. Single-file review build: `SINGLE=1 npm run build`.
- Design rules, fold order and history: `HANDOFF.md`.
